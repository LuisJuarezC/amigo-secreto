# Amigo secreto

Organiza un intercambio de regalos desde el navegador. Cada participante recibe un enlace individual para descubrir a quién le regalará.

## Publicar gratis en GitHub Pages

1. [Crea un repositorio público en GitHub](https://github.com/new) llamado `amigo-secreto`. Activa la opción para inicializarlo con un README.
2. Descomprime el paquete. En el repositorio, elige **Add file → Upload files**. Arrastra `index.html`, `estilos.css`, `sorteo.js` y la carpeta `fuentes` completos a la **raíz**. Pulsa **Commit changes** para guardarlos en la rama `main`.
3. En **Settings → Pages**, elige **Deploy from a branch**, selecciona **main** y **/(root)** y pulsa **Save**.
4. Cuando GitHub termine, abre **Visit site** en esa misma sección. La dirección habitual se verá como `https://TU-USUARIO.github.io/amigo-secreto/`.

Consulta la [guía oficial de GitHub Pages](https://docs.github.com/es/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) si necesitas ubicar los controles.

## Hacer el sorteo

1. Abre la **dirección publicada** y pega los nombres, uno por línea. Diferencia los nombres iguales con un apellido o un apodo.
2. Si ya acordaron el presupuesto en soles, la fecha o el lugar, completa esos campos. En **Exclusiones**, puedes elegir dos personas que no deben tocarse entre sí.
3. Pulsa **Realizar sorteo**. Copia el mensaje de cada persona y pégalo en su chat privado de WhatsApp. Al abrir el enlace, podrá pulsar **Ver a quién me tocó**.

El listado completo y las asignaciones se guardan en el navegador y el perfil desde los que hiciste el sorteo. Vuelve a abrir la misma dirección desde ese navegador para volver a copiar los mensajes. Cada enlace contiene una sola asignación y cualquier persona con ese enlace podrá abrirla.

Puedes preparar otro sorteo con los mismos nombres y ajustar la lista antes de volver a sortear. Si confirmas el nuevo sorteo, se reemplaza el que está guardado en tu navegador y debes enviar los enlaces nuevos. Los enlaces anteriores siguen mostrando el resultado original.

## Probar en tu equipo

Abre `index.html` desde la carpeta descomprimida y usa nombres ficticios. Para compartir enlaces que funcionen en otros dispositivos, realiza el sorteo desde la dirección publicada.
